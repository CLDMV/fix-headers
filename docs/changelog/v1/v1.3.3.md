**Release Date**: July 2026
**Release Type**: Patch

---

## Overview

Version 1.3.3 is a CI-only release: `security-events: write` is dropped from the OpenSSF Scorecard workflow. No runtime code changed.

This version was tagged on `master` but never published to npm; its changes first reached npm in [v1.3.4](./v1.3.4.md). Release PR [#5](https://github.com/CLDMV/fix-headers/pull/5), carrying the fix from [#4](https://github.com/CLDMV/fix-headers/pull/4).

---

## 🔧 CI & tooling

### Scorecard no longer requests `security-events: write`

`scorecard.yml` publishes results to the public OpenSSF transparency log (`publish_results: true`). The publish step rejects a workflow whose token has `security-events` write access ("workflow verification failed: global perm is set to write"). The permission is removed from the workflow, and a comment records the trade-off: the SARIF upload to the Security tab does not run in this configuration, while the public badge does.
