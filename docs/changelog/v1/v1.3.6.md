## Overview

Version 1.3.6 switches the vitest reporter to `dot` to shorten CI logs. No runtime code changed. Release PR [#11](https://github.com/CLDMV/fix-headers/pull/11), carrying [#10](https://github.com/CLDMV/fix-headers/pull/10).

---

## 🔧 CI & tooling

### Quieter test output

`.configs/vitest.config.mjs` sets `reporters: ["dot"]`. In a non-interactive terminal, vitest's default reporter reprints a per-file pass/fail block for every test file in addition to the final summary; `dot` prints one character per test file. The final `Test Files` / `Tests` summary is unchanged.
