# `@cldmv/fix-headers` v2.4.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `release/2.4.0`

---

## Overview

`@Filename` is now written without a leading slash. It is the file's path relative to the project root, and `/src/index.mjs` read as an absolute path, so it is written as `src/index.mjs`. Headers written by earlier versions are rewritten on the next run.

Declaration files that `tsc` emits with a copy of their source's header are now left alone, so `tsc` and fix-headers stop rewriting each other's `@Filename` in committed `types/` folders.

---

## ✨ Features

### `@Filename` without a leading slash ([#199](https://github.com/CLDMV/fix-headers/pull/199))

`src/index.mjs` → `@Filename: src/index.mjs` (was `/src/index.mjs`). A file with no project root above it gets just its file name. An existing header with the leading slash is rewritten on the next run like any other stale field: only the `@Filename` line and `@Last modified time` change, and the recorded `@Last modified by` is kept because the file's content was not edited.

Fixes [#198](https://github.com/CLDMV/fix-headers/issues/198).

## 🐛 Bug Fixes

### Declarations carrying `tsc`'s copy of the source header are skipped ([#196](https://github.com/CLDMV/fix-headers/pull/196))

`tsc` copies a source file's leading comment into the `.d.ts` / `.d.mts` / `.d.cts` it emits, so a generated `types/src/x.d.mts` carried `@Filename` naming `src/x.mts`. fix-headers rewrote it to the declaration's own path, and the next `tsc` build wrote it back, so every build and every fix-headers run changed the committed declarations. A declaration whose header names its own source is now reported in `skipped` and left as `tsc` wrote it. The pairs are `x.d.mts` from `x.mts` / `x.mjs`, `x.d.ts` from `x.ts` / `x.tsx` / `x.js` / `x.jsx`, and `x.d.cts` from `x.cts` / `x.cjs`; the check compares file names only, so both the old slashed and the new `@Filename` form match. A declaration with no header, or one naming any other file (a hand-written declaration that was moved or renamed), is fixed as before.

Fixes [#195](https://github.com/CLDMV/fix-headers/issues/195).

## Upgrade notes

- The first run after upgrading rewrites the `@Filename` line (and `@Last modified time`) in every file that has a header. Land it on its own, as a header-only commit, when no open PRs touch the same files.
- `@Last modified by` and `@Author` are kept on that run.
- Generated declarations whose header names their own source now show up in `skipped`; nothing else about how declarations are handled changes.
