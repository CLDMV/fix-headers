# `@cldmv/fix-headers` v2.3.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `release/2.3.0`

---

## Overview

Version 2.3.0 adds two kinds of files. The `node` detector now handles TypeScript's `.mts` and `.cts` extensions, and a new `c` detector stamps C and C++ sources and headers (`.c .h .cc .cpp .cxx .hh .hpp .hxx`).

Vendored C is left alone: a C file whose opening comments carry someone else's license or copyright notice is skipped and reported in `skipped`, so a bundled library such as the SQLite amalgamation keeps its own notice. Header output for every file type that was already supported is unchanged.

---

## ✨ Features

### `.mts` and `.cts` in the `node` detector ([#193](https://github.com/CLDMV/fix-headers/pull/193))

`.mts` and `.cts` files get the same `/** … */` header as `.ts`. A repo-wide run now stamps them instead of skipping them as unhandled.

### New `c` detector for C and C++ ([#193](https://github.com/CLDMV/fix-headers/pull/193))

The `c` detector is on by default and covers `.c`, `.h`, `.cc`, `.cpp`, `.cxx`, `.hh`, `.hpp` and `.hxx`. The header is a plain `/* … */` comment (not `/** … */`, so Doxygen doesn't take it as the documentation of the first declaration), placed at the top of the file above `#include`, `#pragma once` and include guards. Turn it off with `disabledDetectors: ["c"]`.

### Third-party C is skipped ([#193](https://github.com/CLDMV/fix-headers/pull/193))

The detector reads a C file's prologue (its comments, blank lines and preprocessor lines up to the first line of code). If any comment there mentions a copyright, a license, an `SPDX-License-Identifier` or "public domain" and isn't a fix-headers header, the file is reported in `skipped` and its bytes are not touched. This catches the SQLite amalgamation, whose public-domain notice sits below a few `#define` lines. A file whose first comment is already a fix-headers header is always treated as the project's own. Whole vendor folders can still be left out with `excludeFolders` / `--exclude-folder`.

Fixes [#192](https://github.com/CLDMV/fix-headers/issues/192).

## Upgrade notes

- No breaking changes; drop-in for v2.2.7.
- A repo-wide run now also stamps `.mts`, `.cts` and C/C++ files that were skipped before. Add `"c"` to `disabledDetectors`, or exclude the folders, if you don't want that.
- A project C file whose opening comment mentions a copyright or license (and isn't a fix-headers header yet) is skipped as third-party; the reason is shown in the run output.
