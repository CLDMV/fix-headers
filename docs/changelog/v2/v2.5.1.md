# `@cldmv/fix-headers` v2.5.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/2.5.1`

---

## Overview

The published package is no longer bundled. `dist/` mirrors `src/` one file per module, and the CLI imports the library from those files instead of carrying a second copy of it. The library's behaviour, options and CLI flags are unchanged.

---

## 🐛 Bug Fixes

### `dist/` is built one file per module ([#206](https://github.com/CLDMV/fix-headers/pull/206))

The tsup build bundled the library into `dist/index.mjs` and a second full copy into `bin/fix-headers.mjs`. `scripts/build.mjs` now minifies each `src/**/*.mjs` in place into the same path under `dist/` with esbuild (`bundle: false`), with its imports left as they are. `dist/index.cjs` is still the small CommonJS wrapper copied verbatim from `src/index.cjs`.

The package's `bin` now points at `dist/cli.mjs`, which imports `./index.mjs`, and the `bin/` folder is no longer published. The `fix-headers` command works as before; only a script that ran `node_modules/@cldmv/fix-headers/bin/fix-headers.mjs` by path needs to call `dist/cli.mjs` (or the `fix-headers` command) instead.

Fixes [#205](https://github.com/CLDMV/fix-headers/issues/205).
