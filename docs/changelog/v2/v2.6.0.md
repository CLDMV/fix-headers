# `@cldmv/fix-headers` v2.6.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `release/2.6.0`

---

## Overview

`src/index.cjs` is now the generic CLDMV CommonJS shim, and the TypeScript declarations are generated at build and pack time instead of being committed. `require("@cldmv/fix-headers")` still returns the `fixHeaders` function, and the library's options and CLI flags are unchanged.

---

## ✨ Features

### Generic CommonJS shim ([#212](https://github.com/CLDMV/fix-headers/pull/212))

`src/index.cjs`, copied verbatim to `dist/index.cjs`, is the drop-in shim from the CLDMV package-layout convention instead of a hand-written `.default` unwrap. It returns the single distinct value the ESM entry exports, or the module object when there is more than one. fix-headers exports one function (`fixHeaders`, which is also the default export), so `require()` returns that function as before.

Fixes [#209](https://github.com/CLDMV/fix-headers/issues/209).

## 🔧 CI & tooling

### Declarations are generated, not committed ([#215](https://github.com/CLDMV/fix-headers/pull/215))

`types/` is gitignored. `npm run types:build` runs `tsc` and then stamps headers on its output with the package's own CLI, so each declaration names the file it ships as. `build:ci` and `prepack` both run it, so a published package always carries freshly built declarations. The package's `types` entry points at the generated `types/src/index.d.mts`; the hand-written `types/index.d.mts` re-export and the leftover `types/devcheck.d.mts` are gone. The repo's fix-headers config no longer sets `rewriteDeclarationCopies: false`.

Fixes [#211](https://github.com/CLDMV/fix-headers/issues/211).

### Superseded CI runs cancel outside the release branch ([#213](https://github.com/CLDMV/fix-headers/pull/213))

`ci.yml` takes the CLDMV/.github v4.46.0 concurrency block: only the release base branch keeps a unique group per run, so a newer push cancels the older run on `next`, `hotfixes` and feature branches.

Fixes [#210](https://github.com/CLDMV/fix-headers/issues/210).

## Upgrade notes

- No API or option changes. `require()` and `import` return what they did in 2.5.1.
- TypeScript consumers resolve the declarations through `exports` as before; only the file's path inside the package changed, from `types/index.d.mts` to `types/src/index.d.mts`.
