# `@cldmv/fix-headers` v2.6.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A dev-tooling release: fix-headers' behaviour and options are unchanged. The repository moves to the fleet's new dev tools, `@cldmv/vitest-runner` 1.11.3 and `@cldmv/configs` 1.5.0, and `dependabot.yml` takes the CLDMV/.github v4.47.0 groups.

---

## 🔧 CI & tooling

- `dependabot.yml` takes the npm groups from the CLDMV/.github v4.47.0 template, so the CLDMV dev tools arrive in one `cldmv-dev` PR and the generic patch and minor groups exclude every named family ([#219](https://github.com/CLDMV/fix-headers/pull/219), [CLDMV/.github#593](https://github.com/CLDMV/.github/issues/593)).

Development dependencies only; the runtime dependency (`ignore`) is unchanged.
